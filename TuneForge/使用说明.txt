编曲工坊 TuneForge · 使用说明
================================

一、启动
  双击 TuneForge.exe 即可开始。无需安装，不联网。
  系统要求：Windows 10 / 11（自带 .NET Framework 4.8）。
  若提示缺少 .NET Framework，请到微软官网安装 4.8 后重试。

二、界面
  · 顶部：新建 / 保存 / 打开 / 导出 / 帮助 / 更多菜单，中间是
          播放 · 停止 · 循环、BPM 调速、拍号、长度，右侧为节拍器开关
  · 左侧：轨道列表。点击选中轨道；卡片上的 M 静音、S 独奏；
          音量 / 声像可直接拖动；右上角 + 添加轨道
  · 中间：钢琴卷帘。纵轴音高（左侧为键盘，鼓组轨道自动显示鼓件名），横轴时间
  · 底部：当前轨道的音色选择、音量、声像

三、主菜单（顶部「…」按钮）
  · 新建工程        Ctrl + N   从空白工程开始（默认 4 条轨道）
  · 打开工程…       Ctrl + O
  · 保存 / 另存为…  Ctrl + S / Ctrl + Shift + S
  · 导出 WAV…       Ctrl + E
  · 操作指南        F1
  · 关于编曲工坊

四、编曲操作
  · 左键在卷帘空白处拖动：新建音符（横向拖动决定长度）
  · 拖动音符：移动音高与位置
  · 拖动音符右边缘：调整时值（以原长度为基准按 1/4 拍增减，
    保留 3.92、0.42 这类非整拍尾数；按住 Alt 可自由拖动）
  · 想要精确长度：右键音符 →「长度」直接输入拍数（例如 3.92）
  · 右键音符：弹出音符菜单（力度 / 单独指定音色 / 删除）
  · 双击音符：删除
  · 单击时间尺、或在时间尺上拖动：播放头实时跟随
  · 空格：播放 / 暂停；Delete：删除选中音符；Ctrl+Z：撤销
  · 滚轮：垂直滚动音域；Shift+滚轮：水平滚动时间；Ctrl+滚轮：缩放时间轴
  · 在 BPM / 拍号 / 长度上滚动滚轮可直接增减；BPM 也可左右拖动快速调节
  · 按住 Alt 拖动可关闭网格吸附（默认吸附到 1/4 拍）

五、轨道管理
  · 右键轨道卡片：重命名 / 复制轨道 / 删除轨道 / 更换音色 / 上移 / 下移
  · 轨道名称、音色、音量、声像、静音、独奏都会随工程保存
  · 删除轨道时至少会保留一条，避免空工程

六、单个音符的力度与音色
  · 右键音符 →「力度」可 +10 / -10 或直接输入数值（1–127）
  · 右键音符 →「音色」可以只把这一个音换成别的乐器
    （例如钢琴轨里单独把一个音变成弦乐），选「跟随轨道」可还原
  · 音符的独立音色会写进 .tforge 工程文件

七、音色
  底部音色下拉共 17 种：
    合成器：模拟主音、温暖铺底、拨弦、低音、电钢琴、铃音、
            管风琴、弦乐、明亮方波、柔和钟琴、
            普通钢琴、尼龙吉他、小提琴、竖琴、电贝斯、长笛
    采样器：钢琴 · 采样、小提琴 · 采样、原声长音 · 采样（见第十节）
    鼓组：改成鼓组后，卷帘上的音高会变成鼓件（底鼓/军鼓/闭镲…）

八、保存与导出
  · 工程统一保存在 exe 同级的「工程」文件夹里：
      ...\TuneForge.exe 所在目录\工程\
    首次保存/打开时对话框会自动定位到该文件夹，没有会自动创建。
  · 工程保存为 *.tforge（JSON 格式，可用文本编辑器查看）
  · 导出 WAV：44.1kHz / 16bit / 立体声，自动包含尾音残响
  · 未保存时新建或关闭窗口会先询问

九、小提示
  · 示例工程已包含 4 条轨道（铺底和弦、低音线条、主旋律、鼓组律动），
    可以直接按空格播放试听；点「新建工程」可全部清空从零开始。
  · 工程文件夹里附带了「小星星.tforge」（钢琴旋律 + 贝斯低音 + 钢琴和声，3 轨，12 小节），
    以及它的导出音频「小星星.wav」，可以直接打开试听。
  · 打开工程时视图会自动滚动到该工程的音域中心。
  · 鼓组轨道的音符主要落在 C2–D3 区间，选中鼓组轨道后键盘会自动标注鼓件名。
  · 混音已内置总线软限幅、立体声加宽与高频补偿，导出音量约 -21 dBFS，无需手动调整。
  · 播放引擎使用独立渲染线程 + 371 ms 环形缓冲，正常机器上不会出现断音或电流声。
  · 若机器内存吃紧，可删除「音源」文件夹里的 .sf2 文件，软件会自动退回纯合成器模式。

十、采样音源（SF2）
  软件启动时会自动读取程序目录下「音源」文件夹中的 .sf2 采样库，
  加载成功后状态栏右下角显示「采样音源已就绪：…」，启动约需 5–15 秒（取决于硬盘速度）。
  已接入三个真实采样音色：
    · 钢琴 · 采样      ←「YAMAHA C5 Standard.sf2」254 MB，6 个力度层、44 个音位
    · 小提琴 · 采样    ←「Violins Legato.sf2」11 MB，连奏弦乐，自带循环点
    · 原声长音 · 采样  ←「Acoustic Sustain.sf2」230 MB，16 个音高 × 10 个力度层
  这三个音色在音色菜单中带「· 采样」后缀，其余音色仍是内置合成器。
  想换成别的音源：把同名 .sf2 放进「音源」文件夹即可（需保持文件名一致）；
  删除「音源」文件夹或某个文件时，对应音色会自动退回合成器版本，不影响使用。

—— TuneForge Studio

十、界面与编辑（本次更新）
----------------------------------------
1. 主题：右上角「⋯」菜单 →「主题」，共 8 套（5 暗 + 3 浅）。只换背景与整体明暗，
   音符和强调色保持不变；选择会自动记住，下次启动沿用。
2. 轨道：在左侧轨道卡片上点右键，可「重命名 / 复制 / 删除 / 改颜色 / 上移 / 下移」。
3. 音符：在音符上点右键，可调力度（±1、±10、输入数值）、改长度（按拍输入）、删除。
4. 底栏新增「力度」滑块：选中音符后可直接拖动；快捷键 Ctrl+↑ / Ctrl+↓ 每次 ±1。
5. 拖动音符右边缘改长度时，状态栏实时显示「长度 N 拍」，不再只有松手才看得到。
6. 拨弦、尼龙吉他、竖琴、电贝斯改用 Karplus-Strong 弦模型，声音更接近真实拨弦。
7. 音源管理（右上角「⋯」→「采样管理…」）：左侧列已加载的采样音色（可卸载释放内存），
   右侧列「音源」文件夹里的所有 .sf2（可单独「加载」或从磁盘「删除」），
   底部可「导入新文件…」。把 .sf2 放进「音源」文件夹即自动出现在仓库列表里。
   采样音源数量不设上限，面板顶部显示当前内存占用。

十一、v1.9 补充说明
----------------------------------------
1. 采样管理面板（「⋯」→「采样管理…」）：
   · 左栏「已加载到内存」：每个音色有「重命名」「卸载」；重命名只改显示名，不影响文件。
   · 右栏「音源仓库」：每个 .sf2 有三个独立操作——
       「已加载 / 加载」：是否读进内存（加载后可立刻用，占用内存）
       「默认 ✓ / 默认」：下次启动或新建工程时是否自动加载
       「删除」：从磁盘彻底删除该文件（会二次确认）
   · 顶部显示内存占用与系统内存余量，超过 1200 MB 会变红。
   · 点面板卡片**外面**的暗色区域才会关闭面板，点卡片内空白不会误关。

2. 仅为当前工程导入：菜单里「导入采样音源」有「为所有工程加载」与「仅为当前工程加载」。
   后者导入的音色在新建/打开工程时自动移除并修正引用，适合临时试听。

3. BPM / 拍号 / 长度：除了点击，直接在它们上面滚动滚轮即可增减；
   BPM 也可以按住左右拖动连续调节（40–240）。

4. 底栏「力度」滑块：选中音符后拖动即可；Ctrl+↑ / Ctrl+↓ 每次 ±1。

5. 主题：8 套（暗色 5 + 浅色 3），只改背景明暗，音符颜色不变；
   浅色主题下钢琴键盘、滑块、按钮会自动适配深色前景。

6. 撤销：Ctrl+Z，最多 40 步。拖动音符、改力度、改长度都会进撤销栈。

7. 状态栏会显示当前操作提示（长度、力度、主题、采样导入结果等）。

8. 采样音色的自定义名称会被记住：在采样管理面板里点「重命名」改名后，
   名称会写入程序目录的「设置.txt」（rename=文件名|新名称），
   下次启动或重新加载音源时自动套用。想恢复原名，再重命名回原名即可。
